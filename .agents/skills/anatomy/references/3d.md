# 3D: parts that turn in the drawing

Adapted from the original's `references/3d.md` (MIT) for the Compose kit, `kit/turn/`. The optional
3D mode ("turning groups") lets some parts of a figure move as rigid bodies: a dial or turntable
that spins, fingers that flex, a piece that breaks off and tumbles. Those parts are re-projected
and re-shaded every frame by the kit's own rules and painted in an order solved from separating
planes. Everything else stays ordinary static kit art. A figure that doesn't opt in is untouched.

**Status: beta.** The original's engine is proved on its `examples/turning-dial` and one test
figure; the Compose port is held to it by `TurnParityTest` and `OrbitParityTest`, and draws that
example as Fig 5 (`figures/TurningDial*.kt`). Turn one subject at a time, keep clutter static, and
measure your figure (section 15) before you add parts.

## 1. When a figure earns 3D

Only when the motion is the explanation: a dial whose numbers are read as it turns, a turntable
that shows an object from every side, a wheel pack, a hand that grips or breaks. Never as
decoration. A figure that only needs a part to slide or a needle to swing stays 2D:
`translateAlong` and a re-drawn needle are cheaper and exact.

## 2. The model

- **Groups.** A group is a rigid frame with a pose. Kinds: turn (`turnGroup`, about a vertical axis
  through `pivot`, any angle), slide (`slideGroup`, along a direction, `0…travel`), hinge
  (`hingeGroup`, about any axis through a point, within `range`, in degrees) and free (`freeGroup`,
  any rotation plus a translation, set by the figure every frame). Groups nest: a pose is relative
  to the parent.
- **Rest.** Every constructor takes **world coordinates at rest** (every group value 0, every free
  group `null`). The engine subtracts each group's origin, so the `Recorder`, the kit and the
  engine share one world.
- **Live layers.** A live layer is a set of parts painted together by `drawTurnLayer(controller,
  name)`. Live and static layers stack in the order of `t.stack(listOf(…))`, for example
  `back art → [lock] → mid art → [dial] → light pool → [hand] → LED → front art` in the dial.
- **The identity.** Turning a group by θ about a vertical axis is exactly the kit drawing at
  azimuth `a − θ`, because the kit's light is camera-locked. So every frame of a turn group is the
  kit's own picture at P′(θ), shifted. Hinges and free groups compose matrices instead (correct,
  slightly slower).

## 3. A minimal figure

`figures/TurningDial*.kt` is the reference scene, ported from the original's example: a dial with
a knurl, ticks and numerals, a second turn group (an index wheel under a window), a hinge (a pawl
riding the knurl), a hand of about 80 parts with materials, a three-hinge finger that lifts, a hex
pod that breaks off as a free group, and a shader LED, light pool and sparks
(`TurningDialLight.kt`). Its skeleton:

```kotlin
object MyDial : TurningFigure {
    val P = fitProjection(points, 640.0, 470.0, pad = 22.0, azimuth = 40.0, elevation = 31.0)

    /** One figure value drives the coupled groups. */
    fun follow(values: TurnValues): TurnValues =
        values + TurnValues(mapOf("f2.mcp" to -22 * (values["lift"] ?: 0.0)))

    fun poses(): List<TurnValues> =
        (0 until 720).map { follow(TurnValues(mapOf("dial" to it * 0.5, "lift" to (it % 90) / 90.0))) }

    class Scene(val t: Turning, val r: Recorder, val built: TurnBuild, val statics: List<StaticItem>)

    val scene: Scene by lazy {
        val r = Recorder(P)
        val t = Turning(P, r) // every live shape is recorded for the kit audit too
        val dial = t.turnGroup("dial", Floor(0.0, 0.0))
        val lift = t.hingeGroup("f2.mcp", c1, w, -22.0 to 0.0, dial)
        val hand = t.layer("hand")
        t.stack(listOf("back", "hand", "front"))
        t.round("dial.body", dial, hand, vert(0.0, 0.0), 10.0, 14.4, 50.0,
            style = PartStyle(crease = Tone.Lo, material = Material.Steel),
            details = Details(ribs = RibSpec(10.9, 13.7, 150, seams = RibSeams.Both)))
        t.prism("hand.palm", dial, hand, PALM, 19.4, 8.0, bevel = 0.9,
            style = PartStyle(material = Material.Gold))
        t.tube("cable.red", dial, hand, route, 0.7, TubeOptions(hue = Tone.Red, gaps = gaps),
            PartStyle(material = Material.Rubber))
        // … static kit art recorded as usual, each item a StaticItem(name, layer, shapes) …
        val built = t.build(statics, poses())
        r.settle()
        Scene(t, r, built, statics)
    }

    override fun record() = scene.r

    override fun orbitAudit(quick: Boolean, log: ((String) -> Unit)?) =
        orbit(scene.t, scene.r, P, scene.statics, OrbitOptions(
            sweep = OrbitFamily("sweep", { x -> follow(TurnValues(mapOf("dial" to x))) }, 0.0, 360.0, 0.3, periodic = true),
            clips = listOf(OrbitFamily("tap", { s -> follow(TurnValues(mapOf("dial" to 40 + 12 * s, "lift" to tapAt(s)))) }, 0.0, 4.0, 1 / 60.0)),
            quick = quick, log = log))
}
```

The composable makes one `TurnController(scene.built.data, MyDial::follow)`, drives it from its
own frame loop (`motion.md`) with `controller.set(TurnValues(mapOf("dial" to angle, "lift" to
lift)))`, reads `controller.generation` in the draw phase so each render redraws, and paints
back to front:

```kotlin
for ((_, art) in back) drawArt(art)
drawTurnLayer(controller, "hand")
for ((_, art) in front) drawArt(art)
```

The controller never runs its own loop. A figure that honours `TurnHook.values` (the original's
`window.__isoTurn.set`) stops its tour and holds those values, which is how `capture --turn` shoots
it at a given angle. List the figure in `AUDITED_FIGURES` so `capture --audit` proves it.

## 4. The authoring API

### Scene
| Call | What it does |
|---|---|
| `Turning(P, recorder, scale = 1.0)` | The builder `t`. Pass the kit `Recorder` so every live shape is recorded for the kit audit too. |
| `t.turnGroup(name, pivot: Floor, parent)` | Rotation about the vertical through `pivot`, value in degrees. |
| `t.slideGroup(name, direction, travel, parent)` | Translation, value `0…travel` world units. |
| `t.hingeGroup(name, point, axis, lo to hi, parent)` | Rotation about `axis` through `point`, value in degrees within the range. |
| `t.freeGroup(name, origin, parent)` | A free rigid body (section 7). Value a `FreePose(r = 3×3 \| q = x, y, z, w \| axis, angle, t, world)` or `null` for rest. |
| `t.layer(name)`, `t.stack(listOf(…))` | Live layers and the full stack of live and static layer names, back to front. |
| `t.build(statics, poses, strict = true)` | Solves every pair, proves every static item's layer (`StaticItem(name, layer, shapes)`), packs the runtime data. `poses` is the figure's reachable states: every motion clip, sampled. Throws a readable error on any pair with no separating plane, any static that can't be proved, any non-convex part. `strict = false` keeps interlocked pairs (so a planted fault reaches the audit). |

`t.build` returns a `TurnBuild(data, report, …)`; `data` goes to the `TurnController`. `report`
has `parts`, `groups`, `layers` (per layer: planar, framed, dynamic and skipped pairs), `tight`,
`margins`, `proofs` and `seconds`. Values are `TurnValues(numbers, free)`: group (and figure)
numbers by name, free poses by name; `+` merges two.

### Constructors
Every constructor takes `name, group, layer` and ends with `style: PartStyle(tone = Tone.Hi,
crease = Tone.Faint, lit = false, material = null, owner = null)` and `details: Details`.

| Constructor | Part |
|---|---|
| `t.prism(name, group, layer, plan, z, h, steps = 4, bevel)` | An upright kit slab (the kit `extrude` rule). |
| `t.prism(name, group, layer, frame, polygon, s0, s1, round = 0.0, steps = 4, bevel)` | A convex polygon in `frame` (`Frame(o, a, u, v)`) extruded along `a` from `s0` to `s1`, any axis (the `prismOf` rule). |
| `t.round(name, group, layer, frame, s0, s1, r0, r1 = r0, ends = Flat to Flat, fixed)` | Cylinder or cone frustum; each `RoundEnd` `Flat`, `Dome` (radius must equal the side's: a capsule) or `Open`. One dome and one flat end is a half-capsule, of any length, even one shorter than the radius. A vertical round in an upright group becomes a fixed picture automatically (`fixed = false` stops it). |
| `t.lathe(name, group, layer, frame, profile, slope, radius)` | A general convex smooth body (r(s) concave). Costly; prefer rounds. |
| `t.ball(name, group, layer, c, r, flats = listOf(BallFlat(n, d)))` | A sphere; each flat keeps n·(p − c) ≤ d and draws its rim as a cap, so `n` is the flat's outward normal. Without flats it is a fixed picture and takes no details. It is the costliest kind to draw (section 15). |
| `t.tube(name, group, layer, route, r, TubeOptions(chunk = 6, turn = 20, gaps, breaks, caps, rings, hue, touch), style)` | The kit `tubePieces` semantics, chunked; `hue` is `Tone.Red`, `Green` or `Blue`; records the route. The route runs from mount surface to mount surface. The port, gland or clamp at each end is a separate part with `owner` set to the tube's name, and its span along the route goes in `gaps`. A route that starts at a port's outer face fails `terminals` in the kit audit. |
| `t.fixed(name, group, layer, art, anchor, shapes, hull, frame)` | Any kit art whose picture never changes under the group's motion, moved by a translation. |
| `t.plane(part, o, u, v, PlaneArt(marks), fade = 0.04 to 0.3, normal)` | Lines (`PlaneLine`) or engraved text (`PlaneText`) in a plane of the part (ticks, numerals, label plates), placed by one matrix, faded by facing. |
| `t.billboard(part, at, normal, PlaneArt, fade)` | Screen-aligned art at a projected point (the fallback for a shader glow), faded by facing. Its units are viewBox px centred on the point, not world units: multiply world sizes by `scaleOf(P)`. |
| `t.split(part, n, d)` | Two parts cut by the plane (prism: any plane through it along or across the axis; round: across). The cut edges are not stroked. Use it to break a genuine cycle. |

### Details (in the part's frame: `s` along the axis, `x` and `y` in `u` and `v`)
Each constructor has its own frame and takes its own detail kinds. Anything else is ignored
without a warning.

| Constructor | Frame `(s, x, y)` | Takes |
|---|---|---|
| `round`, `lathe` | `frame`: `s` along `a`, `x` along `u`, `y` along `v` | `seams`, `ribs`, `bolts`, `dots`, `rings`, `rules` |
| `prism(frame, polygon)` | `frame` | `dots`, `seams`, `bevel` |
| `prism(plan, z, h)` | The world: `s` is z, `x` and `y` are world x and y | `dots`, `seams` (z values), `bevel` |
| `ball` with flats | Origin `c`, `a` = the first flat's `n`, `u` and `v` from `frameAlong(c, n)`. The flat is at `s = d` and the far pole at `s = −r` | `bolts`, `dots`, `rings`, `rules` |
| `ball` without flats | None: a fixed picture | Nothing |
| `fixed(frame)` | `frame` (no frame: no details) | `bolts`, `dots`, `rings`, `rules` |

A centre dot on a domed spinner `ball(c, 4.5, listOf(BallFlat(Point3(-1.0, 0.0, 0.0), 0.0)))`
(the flat faces −x, the dome +x) sits at `DetailDot(Point3(-4.5, 0.0, 0.0), Point3(1.0, 0.0,
0.0), size)`: `s = −r` is the pole. For a ring or a rule on a prism face, use `t.plane`.

```kotlin
Details(
    seams = listOf(s…),                                    // rings on rounds, ring seams on prisms
    ribs = RibSpec(s0, s1, count, phase, twist, fade = 0.1 to 0.55, seams = RibSeams.Both, tone),
    bolts = listOf(Bolt(s, r, count, phase, size = 0.5, tone = Tone.Mid)),
    dots = listOf(DetailDot(Point3(s, x, y), normal, size, tone)),
    rings = listOf(DetailRing(Point3(s, x, y), r, normal, tone)),     // become planes
    rules = listOf(DetailRule(listOf(Point3(s, x, y), …), tone)),     // become planes
    bevel = 0.4…1.6,                                                  // prism cap bevel
)
```
Every detail fades with facing: dots and bolts by `smoothstep(0.04, 0.42, n·V)`, ribs per rib,
bevel lines per edge, planes on the group's opacity. No texture stops at full strength.

### Runtime (`TurnController`, `drawTurnLayer`)
| Call | What it does |
|---|---|

| `IsoScope.drawTurnLayer(controller, layer, billboards = 1f)` | Paints a live layer in this frame's order, each part in its material's palette. `billboards` scales the billboard fallbacks, to hand them over to a shader. |
| `controller.angleAt(x, y, z, group)` | The pointer as an unwrapped angle about the group's pivot on the plane at height `z` (drag a dial). |
| `controller.pose(name)` | The group's world pose. |
| `controller.detach(name)` | The `FreePose(world = true, …)` that continues a free group's current pose in the world frame (no jump). |
| `controller.anchor(group, restPoint, restDir)` | Where a rest-world point (and direction) of a group is now: `TurnAnchor(world, screen, direction)`. Spark sources, flame roots, LED positions. |

| `materialPalette(palette, material)`, `materialCss()` | A material's palette for static art; the original's CSS, for the parity test. |
| `TurnState.exact` | Unrounded coordinates. The orbit audit turns it on for the continuity line; a figure never needs it. |
| `turnRotation(axis, degrees)`, `turnCompose(a, b)` | 3×3 rotations, for free poses. |
| `turnFloorOf(scene, group, r)` | The lowest z of a group's parts under rotation `r` (relative to its origin): to set a piece down flush. |
| `TurnHook.values` | A review tool's hold on the figure (`capture --turn`). |

## 5. Part kinds and the rules that keep them true

These are binding; the build and the audit fail without them.
- **Convex parts only.** A stepped dial is tiers; a notched wheel is a hub disc plus rim sectors;
  a U-bracket is three prisms; a hand's shell is plates. `prism` checks its polygon, `lathe` its
  profile.
- **Contacts are flush, tangent or rim-on-flat.** A rim on a sphere is not separable: give the
  ball a flat and land the rim on it. A pad sunk into its host is not allowed in a live layer
  (`separation` fails with `interlock A × B −0.6`).
- **Joints.** The two links stay at least 0.2 apart, and the joint is bridged by a knuckle disc on
  the child group: coaxial with the hinge axis, and touching the parent's link, flush or tangent.
  A disc coaxial with its hinge is invariant under the hinge, so it never collides, and it is the
  contact the kit audit needs. With nothing in the child group touching the parent, `rigid`
  reports every part of the child group as `support loose`. Links meeting at a joint share one
  radius; dome centres sit the same distance from the joint so the gap holds at any angle (two
  domes of radius r at distance c from the joint stay apart while cos(β/2) ≥ r/c). A trunnion
  that ends 0.2 short of the arm it turns in fails `rigid` for the whole head: end it flush.
- **No live line spans two moving groups.** A cable crossing a flexing joint is two routes ending
  in a clip or port on each side of the joint, or crosses at the hinge axis through a rotary union.
  A cable that must reach a turning part from static ground goes up the axis through a slip ring at
  the hub (section 11).
- **Tubes bend nearly flat or inside fittings.** A bend of radius R in a plane tilted θ from
  horizontal, toward the viewer, is an ellipse on screen whose tightest radius is R·sin²(e − θ).
  `folds` fails a bend that turns more than 90° on screen round less than 2r, and `self` one under
  r. So a bend needs **R ≥ 2r / sin²(e − θmax)**, where θmax is the plane's own tilt plus the pitch
  range of every hinge it rides on. At e = 30°:

  | θmax | 0° | 5° | 8° | 10° | 12° | 15° | 20° |
  |---|---|---|---|---|---|---|---|
  | R ≥ | 8r | 11r | 14r | 17r | 21r | 30r | 66r |

  8r is the bound itself on a horizontal plane, not a margin: take 10r. Past about 15° no
  practical radius holds, so turn inside a fitting or run the line straight. Draw bends with
  `fillet(points, R)`, never a view-dependent fillet.
- **Tubes never point along the view.** A tube's tangent elevation stays out of 15°–45° and
  −45°–−15° at e = 30° (`endon`), in every pose, including a hinged link's pitch range.
- **Lathes are the one kind with small residual steps** (≤ 2.5 tone·px² where a band changes
  topology). Prefer rounds, domes and balls with flats for live parts.

## 6. Materials

A part's material is one option of its style (`PartStyle(material = Material.Gold)`). Tones still
come from facing exactly as the kit's do; a material remaps the ramp (the four shades, the top,
paper, outline and line tones, dots and the tube body, shine and shade), with a light and a dark
set each.

| `Material` | Look |
|---|---|
| `Gold` | Champagne-gold anodised aluminium: warm pale top, bronze shadows, dark bronze outline. |
| `Chrome` | Bright polished steel: a light far band, a dark reflection band next to a bright band and a white highlight. Non-monotonic on purpose: the bands move with facing, never jump. |
| `Steel` | Satin steel, monotonic and cool. |
| `Gunmetal` | Dark blue-grey metal with light dots. |
| `Rubber` | Black rubber and cable sheath with a soft sheen. With `hue`, a tube becomes a coloured sheath. |
| `Brass`, `Copper` | Warm metals for fittings, ports, valves. |

Static art takes the same families: `withPalette(materialPalette(palette, Material.Brass)) {
drawArt(art) }` (the dial's index wedge). On a light page a material figure is far stronger than
kit greys: keep the ground (bench, base, plates) in kit tones and put materials on the subject.

## 7. Free groups: parts that break off

`t.freeGroup("pod", origin, dial)` makes a rigid body whose pose the figure sets every frame. At
rest (`null`) it sits exactly where it was built, attached: the parent carries it. To break it
off, start setting a pose relative to the parent: there is no single-frame change because the first
value is the identity.
- **Falling onto the turntable**: keep the parent as the turntable group, so the piece lands and
  then turns with it. Compute the flight as a pure function of time (`TurningDial.breakAt(t)`: a
  somersault about the centroid, a ballistic arc, a flush landing found with `turnFloorOf`, a
  decaying slide and yaw). A pure function can be sampled by the build and the audit, and played
  backwards.
- **Falling off onto the bench**: switch to world space with `controller.detach(name)`, then
  integrate from there.
- **Order**: a free group's parts are paired at runtime with every part of their layer (by screen
  box, then a GJK plane cached per relative pose). The audit samples the clips and reports cycles.
- **Proof**: give the build the clips in `poses()` (every frame of the break at several turn
  angles), and the audit the same clips (`clips`).

## 8. Hinge chains: hands and fingers

Each link is a hinge group whose parent is the previous link. A wrist is a hinge carrying the palm;
a thumb base is a hinge (vertical axis) carrying the thumb chain. Drive the chain from one figure
value through `follow` (`lift` → three angles).
- Pairs on different links are solved at build where possible: a pair whose swept volumes over the
  build's `poses()` have a plane in their common ancestor's frame with margin ≥ 0.1 becomes a
  **framed** plane. Only near-joint pairs stay dynamic. So `poses()` must cover the motion: if a
  gesture leaves the sampled range, the audit's `unseparated` line names the pair ("framed plane:
  … add it to poses()").
- Keep ranges physical and small: a three-link finger at ±5° per joint already reads as a hand
  moving; 20° per joint needs every route and contact re-proved.
- **A route on a hinged link carries the link's pitch range** (section 5): make the line straight
  into a junction box, or move the bend to the parent.

## 9. Painter's order and why it is correct

Every pair of parts that can overlap on screen gets one relation: a plane fixed in their shared
group (planar), a plane fixed in their common ancestor's frame (framed), a GJK plane each frame
(dynamic) or a skip (neighbouring chunks of one route). B is in front of A when n·V > 0 in that
frame. Order is a stable Kahn sort keyed by the previous frame's order; on a stall, edges between
parts whose exact screen hulls are apart are dropped; a remaining stall is a forced pick, counted
and made fatal by the audit.

Correct because two disjoint convex solids whose projections overlap are both hit by some view
ray, and a separating plane crosses that ray once. Flicker-free because a plane's relation flips
only when the plane is edge-on, and then the two footprints lie on opposite sides of a line.

## 10. Shading and fades

- Flat faces use the kit's thresholds through a smoothed staircase: a face holds the kit tone
  except within ±0.035 of a threshold, where it crossfades in 64 steps per band.
- Path coordinates are rounded to 0.01 px; the orbit audit's continuity line switches to exact
  coordinates (`TurnState.exact`), so large flat faces are fine on turning groups.
- Curved surfaces always use analytic iso-light bands, never facets. Bands are born at zero width.
- Faded-line slots hold ribs and bevels: alphas quantised to 1/32.
- `PartStyle(lit = true)` uses the lit tokens; with a material, the material's lit set.

## 11. Static layers and a messy workshop around a turntable

Every static item carries a layer (`StaticItem(name, "back", shapes)`) and the build proves a
constant relation with every live layer over all reachable states, by the first rule that holds: a
**horizontal plane**, the **cylinder rule** (wholly behind or in front of the turn group's swept
cylinder along the view's floor direction), **never overlap** on screen, or a **swept-envelope
plane**. Otherwise: `static S interleaves live layer Λ: split S at z = …, or move it`.
- **Keep clutter outside the swept cylinder or under the turntable plane.** Tall things go behind
  or in front of the cylinder along the view's floor direction; things beside it must be low.
- **Anything under the turntable's lowest live z is behind the live layer**, even when it sits in
  front on the bench: it belongs in a layer under the live one.
- **A cable that must reach the turning part** runs on the bench to the stationary base and
  reaches the turning part through a slip ring at the hub. No route spans static ground and a
  turning group.
- Static cables lie flat on the bench (R ≥ 8r) and end on a port, a reel or a free end. A cable
  resting on the bench needs `touch` on its route, or `clearance` fails it.

## 12. Shaders that follow the turn and the groups

`kit/Shader.kt` has `SKSL_TURN` (`uGroupX/Y/Z/T`, `toGroup`, `toWorld`, `dirToGroup`,
`dirToWorld`, and the cover masks with `coverOf(vb, soft)`) and `skslPose(Name, prefix)` (the same
for any group: `toDial`, `fromDial`, …), the original's `GLSL_TURN` and `glslPose`.
1. **Content on a moving part** (an LED on a fingertip): take the anchor every frame with
   `controller.anchor(group, restPoint, restDir)` and pass it as uniforms. Draw it over the live
   layer and occlude it with the parts painted after it: `controller.cover(listOf(listOf(part)))`,
   and `ink *= 1. - coverOf(vb, .7 * px)`. Every live part is convex, so its hull is its exact
   silhouette.
2. **Content fixed to a turning surface** (oil pooling on the turntable): pass
   `controller.poseUniforms("dial")` and evaluate in rest-world coordinates.
3. **Content in world space** (smoke, sparks after they leave the source): emit from an anchor's
   world position at birth and integrate in world space.
4. **Under a live layer** (light falling on a surface under the parts that cover it): draw the
   shader between two live layers, as the dial's light pool sits between `dial` and `hand`.

Every rule of `shaders.md` still holds, including the billboard fallback handed over with
`(1 − u)/(1 − u·α)` (`drawTurnLayer`'s `billboards`).

## 13. The orbit audit

`orbit(t, r, P, statics, OrbitOptions(…))` (`kit/turn/Orbit*.kt`, the original's
`turn-audit.mjs`) returns an `OrbitResult`; `orbitReport(result)` prints one line per check and
`orbitVerdict(result)` ends `turn audit passed` or `turn audit failed: n problems`. A figure that
implements `TurningFigure` and is listed in `AUDITED_FIGURES` runs it from `capture --audit`, after
the kit audit (`verify.md`). Only a full run ends `turn audit passed`: a run with `only` ends `turn
audit partial: …`, and a quick one `turn audit quick: no problems in what ran (…)`.

Options: `sweep` (an `OrbitFamily(name, at, from, to, frame, periodic = true)`: the turn),
`clips` (gestures, the break-apart: every frame at 60 fps), `poses` (extra states), `crowd` (route
× part pairs exempt from `crowding`, after you have looked), `cover`, `fittings` (stretches of a
route inside a fitting, exempt from `endon`), `quick` (≈ 10× fewer states, for iteration), `only`
(`order`, `rigid`, `swept`, `posed`, `routes`, `coverage`, `continuity`, `depth`; an unknown name
throws), `log`. `order` runs `unseparated`, `cycles`, `forced`, `swaps`; `routes` runs `folds`,
`self`, `crowding`, `endon`; `depth` runs `depth`, `layers`. `separation` always runs. A line that
did not run prints `skipped`.

**Time and how to iterate.** The audit's time grows with parts × states. On this port the turning
dial (88 parts, four turns, two clips) takes about 40 s with `--quick` and about five minutes in full.
Iterate with `--quick`, then run the full audit in the background and read the report when it ends.
Only that run's `turn audit passed` counts.

| Line | Fails on | Fix |
|---|---|---|
| `separation` | A same-group pair with no plane (margin < −0.08) | Split, a flat, or a flush contact |
| `unseparated` | A cross-group pair interpenetrating while their hulls overlap; a framed plane that a state breaks | Fix the contact or the motion; add the motion to `poses()` |
| `cycles` | A cycle among overlapping parts in some state; prints the parts, the state range and the split plane | `t.split` that part on that plane |
| `forced` | The runtime had to force a pick | As cycles |
| `swaps` | Two overlapping parts swap order while overlapping more than 0.25 px² (0.5 px² for a pair built flush) | Look first: shoot `--turn` just before and after the angle, zoomed. Something that appears or vanishes in one step is a drawing bug; a clean swap with sane order on both sides is a wrong plane |
| `layers` | A static item on the wrong side of a live part (ray-cast) | Move it or split it (section 11) |
| `rigid` | Kit clearances, terminals, supports, solid clearances at rest | As in the kit audit. `support loose` on every part of a hinged group: no knuckle disc (section 5) |
| `swept` | A static shape inside a turn group's swept envelope | Move it out of the cylinder |
| `posed` | Shapes of different groups (and moving live × static) passing through each other in any sampled state | The motion or the geometry |
| `folds`, `self`, `endon` | Live routes at every angle and posed state | Section 5 |
| `crowding` | A live route's end or bend lands on the outline of a slender solid at some angle | Look at the angle it names (`--turn`, zoomed); if it reads as two parts, list the pair in `crowd`, or route the line inside the rod |
| `coverage` | A part's recorded shape covers < 60% of its drawing | Record the true shape |
| `depth` | The ray-cast oracle disagrees with the engine order | Report it |
| `continuity` | Per 0.05°: tone step > 1/16 band, a birth > 2 px², a dot α step > 0.01, a faded α step > 1/32 + 0.005, outline motion over 1.5·ω·Δθ + 0.05 px; and the halving test | A detail that stops: fade it. A part whose outline jumps in one step, on a plain kit primitive, is an engine bug |

The halving test re-emits each candidate step at ½, ¼ and ⅛ of itself with exact coordinates,
rasterises the frames at 4× and measures the pixels that change owner, weighted by tone. A smooth
change halves with the step; a jump doesn't. `OrbitParityTest` holds the port to the original on a
small scene with a sunk lug, a pawl that swings through a block and a cable climbing at the viewer.

## 15. Performance

The original measured the cost of a part per frame, in prism units: `fixed` (vertical rounds,
plain balls) 0.5, `prism` 1, tube chunk 2–3, `round` 2.5–4, `ball` with flats 8–10, `lathe` about
25. A **small figure** weighs up to about 50; a **dense** one up to about 230 (the turning dial
weighs about 225). `TurnController.stats.ms` is the render's time: measure your figure while it
turns. Levers, in order: fixed pictures for vertical rounds and plain balls (automatic); planes
for lines and text on a face; framed planes and the relative-pose cache (automatic); render the
live layers on alternate frames when the average `set` time is high; `detail` by speed. Keep small
details as `details`, static clutter as static art, one live layer per independently moving region,
and tubes chunked at 6.

## 16. Known limits

- Vertical turn axes take the azimuth shortcut; other rotations compose matrices.
- Only convex parts. Concave bodies are convex pieces; ball flats replace rim-on-sphere joints.
- Live tubes obey the fold and end-on rules: there are no swept-tube silhouettes, so turns happen
  flat or in fittings, and no route spans two moving groups.
- No automatic splitting: a cycle is an audit failure with a suggested plane.
- Flat faces crossfade over ±0.035 of score (about 8° of turn).
- Lathes keep small residual steps where a band changes topology.
- Free groups pair at runtime with their whole layer; dozens of debris pieces cost GJK while they
  move.
- The original's undocumented experiments (`turn-fixed.mjs`, `canvas-painter.mjs`,
  `gl-shared.mjs`) are not ported.
