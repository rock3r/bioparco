# Local skills

Use these skills for isolated work, static-analysis fixes, and pull-request review.
The repository keeps the PR watcher in sync with its upstream project.

| Skill | Use it for |
|---|---|
| `using-git-worktree` | Isolated feature work without dirtying `main` |
| `addressing-detekt-violations` | Fix findings at the source |
| `babysit-pr` | Watch a PR through CI and Codex review to merge. Vendored from [rock3r/babysit-pr-skill](https://github.com/rock3r/babysit-pr-skill) (see its `VERSION`); update with that repo's `sync.py`. Project settings live in its `config.json`. |
| `anatomy` | Crafted, interactive isometric figures that explain an idea as a real object, built with the `:anatomy` kit. Adapted from Ryan's [Anatomy](https://github.com/wheresryan22/anatomy) skill (MIT). |
